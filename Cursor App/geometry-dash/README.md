# Geometry Dash (style)

A one-button platformer: auto-scroll, jump over spikes and blocks, land on platforms.

## How to play

1. Open `index.html` in your browser (double-click the file, or right-click → Open with → Chrome/Edge).
2. **Space**, **click**, or **tap** to jump.
3. Avoid spikes (red triangles) and blocks (yellow). Use cyan platforms to jump higher.
4. Beat the level or try to beat your best score.

## Controls

- **Space** – jump / start / retry
- **Click / tap** – same

No install needed—just open the HTML file.
